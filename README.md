Entry for the [make.fun bounty](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610): one original line roasting a gadget used every day.

## The roast

> My smartwatch congratulates me for standing up, like sitting was a crime and it is my parole officer with a step counter.

## How it works

`main.ts` (Node 22) writes the roast line to `/output/entry.txt`, after checking the bounty gate: UTF-8 text of 1 to 200 characters, not only whitespace.

```sh
npx tsx main.ts
cat /output/entry.txt
```
